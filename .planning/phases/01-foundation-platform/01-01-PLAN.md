**src/config/tls.ts** — FIPS 140-2/3 cipher suite enforcement for TLS 1.2+. CRITICAL: only FIPS-approved ciphers, no RC4, DES, MD5, SHA-1-based. Node.js 20 uses OpenSSL which in FIPS mode restricts to approved algorithms. This file documents the cipher list and is consumed by the TLS server setup:
```typescript
/**
 * FIPS 140-2/3 compliant TLS configuration.
 * COMP-02: Only FIPS-approved cipher suites. No RC4, DES, MD5, or SHA-1 for signing.
 * Aligned with NIST SP 800-52 Rev 2 TLS profile for federal systems.
 * Node.js 20 with OpenSSL 3.x supports FIPS mode via --enable-fips flag or OPENSSL_CONF.
 */
export const FIPS_TLS_OPTIONS = {
  minVersion: 'TLSv1.2' as const,
  // NIST-approved cipher suites (TLS 1.2 and TLS 1.3)
  // TLS 1.3 suites are always FIPS-compliant in OpenSSL 3.x
  // TLS 1.2 suites: AES-GCM and AES-CBC with SHA-256/384 only
  ciphers: [
    'TLS_AES_256_GCM_SHA384',       // TLS 1.3
    'TLS_AES_128_GCM_SHA256',       // TLS 1.3
    'TLS_CHACHA20_POLY1305_SHA256', // TLS 1.3 (FIPS-approved in FIPS 140-3)
    'ECDHE-RSA-AES256-GCM-SHA384',  // TLS 1.2
    'ECDHE-RSA-AES128-GCM-SHA256',  // TLS 1.2
    'DHE-RSA-AES256-GCM-SHA384',    // TLS 1.2
    'DHE-RSA-AES128-GCM-SHA256',    // TLS 1.2
  ].join(':'),
};

// Forbidden ciphers — must NEVER appear in production TLS negotiation
export const FORBIDDEN_CIPHERS = ['RC4', 'DES', '3DES', 'MD5', 'NULL', 'EXPORT', 'aNULL', 'eNULL'];
```

**src/middleware/https-redirect.ts** — COMP-04 HTTPS enforcement:
```typescript
import { Request, Response, NextFunction } from 'express';
import { config } from '../config/env';

/**
 * COMP-04: Redirect all HTTP requests to HTTPS in production.
 * Uses X-Forwarded-Proto header for reverse-proxy environments (Azure App Gateway, AWS ALB).
 */
export function httpsRedirect(req: Request, res: Response, next: NextFunction): void {
  if (!config.FORCE_HTTPS) {
    return next();
  }
  const proto = req.headers['x-forwarded-proto'] || req.protocol;
  if (proto !== 'https') {
    res.redirect(301, `https://${req.hostname}${req.url}`);
    return;
  }
  next();
}
```

**src/app.ts** — Express application factory:
```typescript
import express from 'express';
import helmet from 'helmet';
import session from 'express-session';
import { config } from './config/env';
import { httpsRedirect } from './middleware/https-redirect';

export function createApp(): express.Application {
  const app = express();

  // COMP-04: HTTPS redirect (before all other middleware)
  app.use(httpsRedirect);

  // COMP-02/COMP-04: Helmet security headers — HSTS, CSP, no-sniff
  app.use(helmet({
    hsts: {
      maxAge: 63072000,      // 2 years
      includeSubDomains: true,
      preload: true,
    },
    contentSecurityPolicy: {
      directives: {
        defaultSrc: ["'self'"],
        scriptSrc: ["'self'"],
        styleSrc: ["'self'", "'unsafe-inline'"],
        imgSrc: ["'self'", 'data:'],
        connectSrc: ["'self'"],
        frameSrc: ["'none'"],
        objectSrc: ["'none'"],
      },
    },
    referrerPolicy: { policy: 'strict-origin-when-cross-origin' },
  }));

  app.use(express.json({ limit: '1mb' }));
  app.use(express.urlencoded({ extended: false, limit: '1mb' }));

  // Session management — SESSION_SECRET must be 32+ chars (FIPS-compliant HMAC)
  app.use(session({
    secret: config.SESSION_SECRET,
    resave: false,
    saveUninitialized: false,
    cookie: {
      secure: config.NODE_ENV === 'production',
      httpOnly: true,
      sameSite: 'lax',
      maxAge: 8 * 60 * 60 * 1000, // 8 hours
    },
  }));

  // Health check — no auth required
  app.get('/health', (_req, res) => {
    res.json({ status: 'ok', timestamp: new Date().toISOString() });
  });

  return app;
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API | HTTP requests entering the Express app from unauthenticated clients; body/header/query data crosses into handlers |
| env→process | Environment variable values crossing into config parsing; misconfigured values could expose secrets or disable security controls |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information disclosure | `.env` / secrets in source | mitigate | `.gitignore` includes `.env`; `.env.example` contains only placeholder strings — enforced by `grep` check in `<verify>`. `SESSION_SECRET` minimum length validated by Zod `z.string().min(32)` in `src/config/env.ts`. |
| T-01-02 | Elevation of privilege | HTTP protocol downgrade (no HTTPS enforcement) | mitigate | `src/middleware/https-redirect.ts` issues 301 redirect when `FORCE_HTTPS=true`; Helmet HSTS header sets `maxAge=63072000` with `includeSubDomains` in `src/app.ts` `helmet({hsts:{...}})` call. |
| T-01-03 | Information disclosure | Non-FIPS cipher suites negotiated in TLS | mitigate | `src/config/tls.ts` defines FIPS-approved cipher list (AES-GCM + SHA-256/384 only); forbids RC4, DES, 3DES, MD5, NULL, EXPORT.
