**src/routes/records.ts — Public records page router:**

```typescript
import express from 'express';
import { RecordService } from '../services/record';
const router = express.Router();
const recordService = new RecordService();

// GET /records/:record_id
router.get('/:record_id', async (req, res, next) => {
  try {
    const scope = (req.session?.user?.role === 'CURATOR' || req.session?.user?.role === 'ADMIN')
      ? 'CURATOR' : 'PUBLIC';
    const record = await recordService.getRecord(req.params.record_id, scope);
    if (!record) return res.status(404).render('404', { message: 'Record not found' });
    // Compute derived labels for template
    const maturityLabels = {
      IDEA: 'Idea', EXPERIMENT_POC: 'Experiment / POC',
      PROTOTYPE_PILOT: 'Prototype / Pilot', PRODUCTION_VALIDATED: 'Production / Validated Pattern',
      ARCHIVED: 'Archived'
    };
    const reviewStatusLabels = {
      SUBMITTED: 'Submitted', CURATED: 'Curated',
      TECHNICALLY_REVIEWED: 'Technically Reviewed', SECURITY_REVIEWED: 'Security Reviewed',
      POLICY_REVIEWED: 'Policy Reviewed', VALIDATED_FOR_REUSE: 'Validated for Reuse',
      SUPERSEDED_RETIRED: 'Superseded / Retired'
    };
    res.render('records/show', {
      record,
      maturityLabel: maturityLabels[record.maturity_level] || record.maturity_level,
      reviewStatusLabel: reviewStatusLabels[record.review_status] || record.review_status,
      defaultPerspective: record.default_perspective || 'EXECUTIVE',
    });
  } catch (err) { next(err); }
});

export { router as publicRecordPagesRouter };
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| db→render | innovation_records fields (title, problem_statement, owner_name, etc.) stored in DB cross into EJS HTML output — stored XSS if not escaped |
| client→server | :record_id path parameter from URL crosses into DB query |
| external→user | artifact_links.url values stored in DB are rendered as href in <a> tags — open redirect / malicious link risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering (stored XSS) | src/views/records/show.html — EJS renders title, problem_statement, owner_name and all text fields from DB into HTML | mitigate | All EJS output uses `<%=` (HTML-escaped by EJS) in `src/views/records/show.html` — never `<%-` for user-controlled record fields; grep verification in verify step confirms no unescaped output for `record.*` variables |
| T-03-06 | Information disclosure | GET /records/:record_id — non-PUBLISHED record accessible to public | mitigate | Route handler in `src/routes/records.ts` calls `recordService.getRecord(id, 'PUBLIC')` which returns null for non-PUBLISHED; handler returns `res.status(404).render('404')` — no record data serialized; tested in E2E scenario 4 |
| T-03-07 | Tampering | :record_id URL parameter piped into DB query | mitigate | Knex parameterized query in `src/repositories/record-repository.ts::findById` binds record_id as query param — never string-interpolated; invalid UUIDs return null → 404 |
| T-03-08 | Information disclosure (open redirect via artifact URL) | artifact_links.url rendered as href — user may be redirected to a malicious URL stored in DB by a curator | accept | artifact_links.url is constrained at creation to HTTPS URLs (enforced by DB DDL constraint and service-layer validation from 02-01, T-02-05). Accepted: curator-submitted URLs are already trusted within the curator access boundary; the page renders "opens in a new tab" notice; `rel="noopener noreferrer"` prevents the opened page from accessing the opener. No further mitigation required at the render layer. |
| T-03-09 | Tampering (XSS via artifact link label) | artifact_links.label rendered inside <a> tag body | mitigate | `link.label` in `src/views/records/show.html` uses `<%=` (EJS-escaped) — the label is HTML-escaped before being placed in the link body; link.url is used as href attribute value, also `<%=`-escaped preventing attribute injection |
</threat_model>
